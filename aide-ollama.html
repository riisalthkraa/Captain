Utiliser Ollama avec la version en ligne

Ollama fait tourner une IA gratuite sur votre ordinateur : les questions de votre enfant ne partent nulle part. L'IA reste facultative : Cap'taine fonctionne entièrement sans elle.

Le plus simple : l'appli pour Windows

L'appli Cap'taine n'a besoin d'aucun réglage : elle trouve Ollama, le démarre, télécharge le modèle conseillé et l'arrête quand vous fermez Cap'taine.

Télécharger pour Windows

Windows affiche un avertissement ? Voici comment faire.

Avec la version en ligne, en six étapes

Un navigateur n'a pas le droit de parler à Ollama sans son accord : il faut autoriser cap-tain.fr une fois.

  1. Installez Ollama depuis sa page officielle : ollama.com/download.
  2. Quittez Ollama : clic droit sur son icône près de l'horloge, puis « Quit Ollama ».
  3. Autorisez cap-tain.fr. Ouvrez PowerShell (menu Démarrer, tapez « PowerShell »), collez cette commande, puis appuyez sur Entrée : [Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS", "https://cap-tain.fr", "User")

    Sans PowerShell : dans le menu Démarrer, cherchez « Modifier les variables d'environnement pour votre compte », puis ajoutez la variable OLLAMA_ORIGINS avec la valeur https://cap-tain.fr.

  4. Relancez Ollama depuis le menu Démarrer.
  5. Téléchargez le modèle conseillé (environ 6,6 Go, conseillé avec 16 Go de mémoire ou plus) : ollama pull gemma4:e4b
  6. Dans Cap'taine : Réglages, Espace parent (code parent), « IA de Cap'taine », « Ollama », puis « Réessayer ». Choisissez le modèle et touchez « Utiliser ce modèle ».

Deux réglages de l'appli Ollama

  • Taille du contexte (« Context length ») : laissez la valeur par défaut, entre 4K et 8K. Jamais au maximum : l'IA deviendrait très lente et prendrait toute la mémoire de l'ordinateur.
  • « Expose Ollama to the network » : désactivé. Sinon, d'autres appareils de votre réseau pourraient utiliser l'IA de cet ordinateur.

Et la sécurité de l'enfant ?

Cap'taine demande à l'IA de refuser gentiment les sujets violents, pour adultes ou dangereux, quel que soit le modèle. Les modèles dont les protections ont été retirées (« abliterated », « uncensored »…) sont masqués dans la liste, et le parent est prévenu s'il en choisit un.
